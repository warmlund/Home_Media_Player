# Home Media Player
> A media player with the purpose of playing a slideshow of both images and videos. Media and playlists is either loaded as playlists from a local database using Entity Framework or from the desktop as .json files.
Playlists can be edited, created, removed and saved to the database or as json files.

## General Information
- Implements event handling and delegates simulating take off, landing and altitude changes for flights
-  Implements unit testing for all classes in the BLL layer
-  Built with a three-layered architecture
-  Uses a MVVM pattern in the PL layer


## Technologies Used
- Programming Language: C#
- Framework: .NET (8.0)
- UI Framework: Windows Presentation Foundation (WPF)


## Features
- Plays images and videos as a slideshow at a user input interval
- Load and save playlists
- Edit playlists in the media player
